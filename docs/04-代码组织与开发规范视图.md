## 模块职责划分与依赖方向

```
main.py (PyInstaller 入口)
 │  - 初始化 QApplication
 │  - 创建 MainWindow（含下载/代理/设置三页）
 │  - 启动 HTTP 加速服务线程
 │  - app.exec() 进入 Qt 事件循环
 │
 ├──▶ github_speedup/gui/ (UI 层)
 │     ├── main_window.py     主窗口布局与页面切换
 │     ├── download_page.py   下载任务创建/进度/取消/删除
 │     ├── proxy_page.py      代理管理/测速/预检/导入导出
 │     └── settings_page.py   设置读取/保存/记录管理
 │
  ├──▶ github_speedup/core/ (核心引擎层)
  │     ├── downloader.py      多代理并行分片下载引擎 (legacy 主路径)
  │     ├── aria2_downloader.py aria2c 直连镜像多源下载 + 代理记录
  │     ├── proxy_manager.py   代理列表加载/两阶段测速/静默管理
  │     ├── local_viper_proxy.py 遗留 vipertls 本地代理（下载组件不再使用）
  │     ├── records.py         代理成功/失败记录管理
  │     ├── settings.py        设置管理
  │     ├── utils.py           共享 Transport/vipertls/浏览器头
  │     └── logger.py          运行时访问日志
 │
 └──▶ github_speedup/server/ (HTTP 服务层)
       └── proxy_server.py    HTTP 加速服务（接收请求→代理转发）
```

## 命名规范

| 类别 | 规范 | 示例 |
|------|------|------|
| 模块/包名 | 全小写蛇形 | `downloader.py`, `proxy_manager.py` |
| 类名 | PascalCase | `ProxyItem`, `TaskInfo`, `ProxyRecord` |
| 函数/方法 | snake_case | `start_download()`, `load_active_proxies()` |
| 常量 | UPPER_SNAKE_CASE | `MAX_CONCURRENT`, `PART_SIZE_BYTES` |
| 私有成员 | 前置下划线 | `_save_tasks()`, `_test_single_proxy()` |

## 并发安全

| 数据 | 保护方式 | 所在文件 |
|------|---------|---------|
| 代理列表 `proxies: list[ProxyItem]` | `threading.Lock` | core/proxy_manager.py |
| 下载任务 `tasks: list[TaskInfo]` | `threading.Lock` | core/downloader.py |
| 取消标志 `_cancelled` | `threading.Event` | core/downloader.py |
| 下载统计 `total_downloaded` | `threading.Lock` | core/downloader.py |
| 代理使用计数 `proxy_used` | `threading.Lock` | core/downloader.py |
