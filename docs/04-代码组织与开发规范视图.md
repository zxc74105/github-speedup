## 模块职责划分与依赖方向

```
     main.go (CLI 编排层)
     │  - 解析 CLI 参数 (flag)
     │  - 创建 ProxyPool
     │  - 调度 Worker goroutine
     │  - 协调下载完成
     │  - 调用文件合并
     │
     ├──▶ proxy.go (代理管理层)
     │     - ProxyPool 结构体
     │     - Assign/Fail/Release 生命周期
     │     - 线程安全 (sync.Mutex)
     │
     └──▶ utils.go (工具层)
           - GetFileInfo()     HEAD 请求获取文件元数据
           - DivideFileIntoParts() 分片计算
           - DownloadPartialFile() 通过代理下载分片
           - ConcatenateFiles()    合并分片
           - progressReader / trackReader  流包装
           - 速度/ETA 计算
```

## 命名规范

| 类别 | 规范 | 示例 |
|------|------|------|
| 包名 | 全小写，单层 | `package main` |
| 导出类型 | PascalCase | `ProxyPool`, `FilePart` |
| 未导出类型 | camelCase | `progressReader`, `trackReader` |
| 导出函数 | PascalCase | `GetFileInfo()`, `ConcatenateFiles()` |
| 未导出函数 | camelCase | `calculateCurrentSpeed()`, `reportProgress()` |
| 常量 | camelCase | `version = "1.1.0"` |
| CLI 参数名 | 全小写中划线 | `-max`, `-retry`, `-part`, `-json-output` |

## 代码规范

| 规则 | 说明 |
|------|------|
| 包设计 | 全部在 `package main`，未拆分独立 package |
| 错误处理 | Go 标准模式：`if err != nil { return }` |
| 日志 | 使用 `charmbracelet/log`，支持 `-debug` 级别 |
| 并发安全 | `sync.Mutex` 保护 ProxyPool 共享状态 |
| 超时控制 | `context.WithCancel` 实现 per-worker 超时 |
| 资源清理 | `defer` 确保 HTTP Body / 文件描述符关闭 |
