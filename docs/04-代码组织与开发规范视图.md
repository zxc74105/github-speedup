## 模块职责划分与依赖方向

```
     main.go (应用入口)
     │  - 初始化 Wails App
     │  - OnStartup: 初始化日志/设置/自动启动 HTTP 服务
     │  - 注册 Bindings (Download/Proxy/Config/ServerAPI)
     │
     ├──▶ bindings/ (API 绑定层)
     │     ├── download.go  下载任务创建/取消/删除/持久化
     │     ├── proxy.go     代理管理/测速/预检/导入导出
     │     ├── config.go    设置读取/保存/重置/记录管理
     │     ├── server.go    HTTP 加速服务（接收请求→代理转发）
     │     ├── server_api.go HTTP 服务启停控制
     │     └── logger.go    运行时访问日志
     │
     └──▶ core/ (核心引擎层)
           ├── downloader.go  多代理并行分片下载引擎
           ├── utils.go       共享 Transport/路径/验证工具
           └── default_proxies.go 默认代理硬编码
```

## 命名规范

| 类别 | 规范 | 示例 |
|------|------|------|
| 包名 | 全小写 | `package bindings` |
| 导出类型 | PascalCase | `ProxyAPI`, `DownloadTask`, `TaskInfo` |
| 未导出类型 | camelCase | `cancelEntry`, `activeEntry` |
| 导出函数 | PascalCase | `StartBackgroundDownload`, `NewProxyAPI` |
| 未导出函数 | camelCase | `loadActiveProxies`, `testSingleProxy` |

## 并发安全

| 数据 | 保护方式 | 所在文件 |
|------|---------|---------|
| 代理列表 `proxies []ProxyItem` | `sync.Mutex` | bindings/proxy.go |
| 下载任务 `tasks []*TaskInfo` | `sync.Mutex` | bindings/download.go |
| 取消函数列表 `cancels []cancelEntry` | `sync.Mutex` | core/downloader.go |
| 下载统计 `totalDownloaded` | `sync.Mutex` | core/downloader.go |
