# 视图20-UI设计与交互规范

## 覆盖范围
终端用户界面 (TUI) 完整设计

## 技术选型

| 选项 | 选择 | 原因 |
|------|------|------|
| UI 框架 | **bubbletea** (charmbracelet/bubbletea) | 与现有 lipgloss/log 同生态；Go 原生 TUI 框架；跨平台 |
| 组件库 | **bubblezone + bubbles** (charmbracelet/bubbles) | 官方配套组件 (table/spinner/viewport/textinput等) |
| 布局 | **lipgloss** (内置布局) | 已引入；支持表格、网格、弹性布局 |
| 渲染 | 终端 ANSI (无 WebView) | 无额外依赖，即开即用 |

## 面板详解

### 1. 标题栏 (Header)

```
📥 Multi-Proxy Downloader  v1.2.0          [IDLE]    2026-07-25
```

| 元素 | 内容 | 说明 |
|------|------|------|
| 图标 | 📥 | 固定图标 |
| 标题 | `Multi-Proxy Downloader` | 应用名 |
| 版本 | `v1.2.0` | 当前版本 |
| 状态 | `[IDLE]` / `[PREP]` / `[DL]` / `[PAUSE]` / `[DONE]` / `[ERR]` | 全局状态，颜色编码 |
| 日期 | `2026-07-25` | 当前日期 |

**状态颜色映射：**

| 状态 | 标签 | 颜色 | 含义 |
|------|------|------|------|
| IDLE | `[IDLE]` | 蓝色 | 等待用户输入 |
| PREP | `[PREP]` | 黄色 | 正在解析/预检 |
| DL | `[DOWNLOADING]` | 绿色 | 下载中 |
| PAUSE | `[PAUSED]` | 黄色 | 暂停 |
| DONE | `[COMPLETED]` | 绿色(加粗) | 完成 |
| ERR | `[ERROR]` | 红色 | 出错 |

```
┌─ URL ─────────────────────────────────────────────────────────┐
│  https://github.com/user/repo/releases/download/v1.0/file.zip  │
└────────────────────────────────────────────────────────────────┘
```

| 交互 | 行为 |
|------|------|
| 聚焦时 | 光标闪烁，可输入/粘贴 URL |
| Enter | 开始解析（触发代理预检） |
| 空状态 | 浅色占位文字 `输入或粘贴下载链接...` |
| 粘贴 | 支持 Ctrl+V / 右键粘贴 |
| 历史 | ↑↓ 键切换历史 URL（最近 10 条） |

后端数据：`fileURL string`

**状态图标：**

| 图标 | 含义 |
|------|------|
| `⏳` | 测速中 |

| `⚠️` | 可用但较慢（<1 Mbps） |
| `❌` | 不可用 |
| `⏸` | 用户手动跳过 |
| ` ` | 未测速 |

**交互：**

| 操作 | 行为 |
|------|------|
| Tab/↑↓ | 导航行 |
| Space | 切换启用/禁用 |
| `/` | 搜索过滤 |
| `s` | 按速度排序 |
| `r` | 重新测速选中的代理 |
| `R` | 重新测速全部 |
| `a` | 全选 |
| `A` | 取消全选 |

```go
// 新增全局 UI 状态
type AppState int
const (
    StateIdle AppState = iota
    StatePreparing
    StateDownloading
    StatePaused
    StateCompleted
    StateError
)

// 新增 UI 模型 (bubbletea Model)
type UIModel struct {
    // 面板焦点
    activePanel int // 0:URL  1:代理列表  2:Worker  3:日志

    // 输入
    urlInput     string
    urlHistory   []string
    proxyFilePath string

    // 代理列表 (视图09 数据)
    proxyItems []ProxyUIItem
    proxyFilter string

    // Worker 状态 (视图06 数据)
    workers []WorkerStatus

    // 全局进度 (视图05 数据)
    totalBytes     int64
    downloadedBytes int64
    currentSpeed   float64
    eta            time.Duration
    completedParts int
    totalParts     int
    proxyErrors    int

    // 日志
    logBuffer []LogEntry
    logOffset int

    // 控制
    state    AppState
    pauseCh  chan struct{}
    cancelFn context.CancelFunc
}
```

## 实现路线图

```
第1步: 搭建 bubbletea 骨架
  ├── 新增 components/tui.go (主 Model/Update/View)
  ├── 新增 components/header.go
  ├── 新增 components/panels.go (各面板)
  └── main.go: 添加 --tui 参数切换 UI 模式

第2步: 集成现有逻辑
  ├── 将 main.go 的下载循环改为可取消 (context)
  ├── 通过 channel 将下载进度推送到 TUI
  └── ProxyPool + Worker 状态实时上报

第3步: 代理预检功能
  ├── 启动时/手动触发 → 并发测试所有代理
  ├── HTTP HEAD + 下载 1MB 测试片段
  └── 结果写入 ProxyUIItem.SpeedMbps

第4步: 交互完善
  ├── 快捷键系统
  ├── 弹窗系统 (帮助/确认/完成)
  ├── 搜索/过滤/排序
  └── 历史记录持久化

第5步: 高级功能
  ├── 速度趋势图表 (ASCII 绘图)
  ├── 多任务队列 (批量下载)
  └── 配置持久化 (JSON)
```
