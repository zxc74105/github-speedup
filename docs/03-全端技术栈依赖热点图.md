# 视图03-全端技术栈依赖热点图

## 覆盖范围
整个项目（Python 后端 + PySide6 Qt6 原生 UI）

## 核心依赖

```
                    github-speedup (Python)
                           │
                           ▼
                PySide6 (Qt6 桌面框架)
                requests (HTTP 客户端)
                PyInstaller (打包)
```

Python 后端核心依赖：**PySide6**（GUI 框架）、**requests**（HTTP 客户端，替代标准库）。

## 标准库使用热图

| 包 | 使用文件 | 用途 |
|----|---------|------|
| threading / queue | core/downloader.py | 线程池、任务队列、并发控制 |
| http.client / urllib.request | core/utils.py, core/downloader.py | HTTP 客户端、Range 请求 |
| json | core/settings.py, api/*.py | JSON 序列化/反序列化 |
| os / pathlib | 多处 | 文件创建、路径操作 |
| time | core/downloader.py, api/proxy_api.py | 超时计算、速度统计、测速 |
| logging | core/logger.py | 访问日志 |
| ssl | core/utils.py | TLS 配置（跳过验证） |
| contextlib | core/downloader.py | 下载取消、超时控制 |
| dataclasses | 数据模型 | 数据结构定义 |
