# 视图03-全端技术栈依赖热点图

## 覆盖范围
整个项目（Go 后端 + React 前端）

## 核心语言与运行时

```
┌─────────────────────────────────┐
│         Go 1.26                 │
│  编译型 · 静态链接 · 单二进制     │
│  无外部运行时依赖                  │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│   Wails v2 + React 19 + TS     │
│   桌面端 WebView 渲染            │
│   前端: Node.js 构建             │
└─────────────────────────────────┘
```

## 后端依赖

```
                         github-speedup (Go)
                               │
                               ▼
                      github.com/wailsapp/wails/v2
                        (桌面框架 + WebView + Runtime)
```

Go 后端**无其他外部依赖**（全部使用标准库 net/http/io/os/sync/...）。

## 标准库使用热图

| 包 | 使用文件 | 用途 |
|----|---------|------|
| net/http | core/utils.go, core/downloader.go, bindings/*.go | HTTP 客户端、Range 请求、代理 Transport、HTTP 服务 |
| io | core/downloader.go | 流式读写、文件复制 |
| os | bindings/*.go, core/utils.go | 文件创建、路径操作、JSON 持久化 |
| sync | bindings/proxy.go, core/downloader.go | Mutex 保护并发安全 |
| context | main.go, core/downloader.go | 下载取消、超时控制 |
| encoding/json | bindings/*.go, core/downloader.go | JSON 序列化/反序列化（持久化） |
| fmt / strings / strconv | 多处 | 字符串处理、URL 拼接 |
| time | bindings/proxy.go, core/downloader.go | 超时计算、速度统计、测速 |
| path/filepath | bindings/*.go, core/utils.go | 路径处理 |
| sort | bindings/download.go | 代理记录排序 |
| crypto/tls | core/utils.go, bindings/proxy.go, bindings/server.go | TLS 配置（跳过验证） |
