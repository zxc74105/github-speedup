## 依赖热点等级

| 依赖 | 等级 | 调用位置 | 可替代性 | 说明 |
|------|------|---------|---------|------|
| **标准库** (net/http, io, os, sync, etc.) | 🔥🔥🔥🔥🔥 | 全部源文件 | ❌不可替代 | 核心 HTTP/文件/并发能力 |
| **progressbar/v3** | 🔥🔥🔥 | main.go:214-230 | ⚠️可替代 | 仅用于进度条显示，可替换为其他进度库 |
| **charmbracelet/log** | 🔥🔥 | main.go:40-50, utils.go | ⚠️可替代 | 日志输出，可替换为 logrus/zap |
| **lipgloss** | 🔥 | main.go:45-55 | ✅可替代 | 仅用于日志样式美化，移除不影响功能 |
| 其余 23 个间接依赖 | 🔹 | 传递依赖 | ⚠️ | 全部为 lipgloss/log 的传递依赖 |

## 依赖版本锁定

```
go.mod 中所有依赖均锁定具体版本（含 indirect），
通过 go.sum 完整性校验，确保可复现构建。
```

## 标准库使用热图

| 包 | 使用文件 | 用途 |
|----|---------|------|
| net/http | utils.go | HTTP 客户端、Range 请求、代理 Transport |
| io / io/ioutil | utils.go | 流式读写、文件复制 |
| os | main.go, utils.go | 文件创建、路径操作、信号处理 |
| sync | proxy.go | Mutex 保护 ProxyPool 并发安全 |
| context | main.go, utils.go | 超时取消、Worker 生命周期控制 |
| flag | main.go | CLI 参数解析 |
| fmt / strings / strconv | 多处 | 字符串处理 |
| time | utils.go | 超时计算、速度统计 |
| path/filepath | utils.go | 路径处理 |
| sort / math | utils.go | 分片排序、速度计算 |
| encoding/json | main.go, utils.go | JSON 日志输出 |
