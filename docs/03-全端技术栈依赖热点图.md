# 视图03-全端技术栈依赖热点图

## 覆盖范围
整个项目（Python 后端 + PySide6 Qt6 原生 UI）

## 核心语言与运行时

```
┌─────────────────────────────────┐
│         Python 3.10+            │
│  解释型 · 动态绑定 · 单 .exe    │
│  依赖 Python 运行环境（打包后无） │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│   PySide6 Qt6 原生桌面          │
│   桌面端 QWidget 渲染           │

```

## 核心依赖

```
                    github-speedup (Python)
                           │
                           ▼
                 PySide6 (Qt6 桌面框架)
                 requests (HTTP 客户端)
                 vipertls (Chrome TLS 指纹)
                 aria2c (多源并行下载)
                 PyInstaller (打包)
```

Python 后端核心依赖：**PySide6**（GUI 框架）、**requests**（HTTP 客户端）、**vipertls**（代理测试专用 TLS 指纹）、**aria2c**（大文件多源下载）。

## 标准库使用热图

| 包 | 使用文件 | 用途 |
|----|---------|------|
| threading / queue | core/downloader.py, core/proxy_manager.py | 线程池、任务队列、并发控制 |
| http.client / urllib.request | core/utils.py | HTTP Transport 配置 |
| json | core/settings.py, core/records.py, core/downloader.py | JSON 序列化/反序列化 |
| os / pathlib / shutil | 多处 | 文件创建、路径操作、分片合并 |
| time | core/downloader.py, core/proxy_manager.py | 超时计算、速度统计、测速 |
| logging | core/logger.py | 访问日志 |
| ssl | core/utils.py | TLS 配置（跳过验证） |
| contextlib | core/downloader.py | 下载取消、超时控制 |
| dataclasses | 数据模型 | 数据结构定义 |
| subprocess | core/aria2_downloader.py | 启动 aria2c 子进程 |
