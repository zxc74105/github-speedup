# 视图09-客户端数据存储与配置图（简化版）

## 覆盖范围
CLI 工具本地的文件存储与配置

## 说明
本项目为 CLI 工具，**无数据库/无持久化存储**，所有数据均为运行时临时文件。

## 存储全景

```
┌─────────────────────────────────────────────────────────────────────┐
│                    运行目录 / 指定输出目录                              │
│                                                                      │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │                    输入文件                                    │    │
│  │  proxies.txt  (默认) 或 自定义路径 (-proxy 参数)               │    │
│  │  格式: 每行一个代理 URL                                       │    │
│  │  示例:                                                      │    │
│  │    http://user:pass@host:port                                │    │
│  │    https://host:port                                         │    │
│  │    socks5://host:port                                        │    │
│  └─────────────────────────────────────────────────────────────┘    │
│                                                                      │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │                    临时输出文件（运行时）                        │    │
│  │                                                               │    │
│  │  📄 filename.0.part     (Worker #1 下载的分片 0)              │    │
│  │  📄 filename.1.part     (Worker #2 下载的分片 1)              │    │
│  │  📄 filename.2.part     (Worker #3 下载的分片 2)              │    │
│  │  ...                    (依此类推)                            │    │
│  │  📄 filename.N.part     (最后一个分片)                         │    │
│  │                                                               │    │
│  │  📄 filename.info.txt   (元数据: 文件名:文件大小)               │    │
│  │    格式: "filename.zip:104857600"                             │    │
│  │    用途: 断点续传检测（文件大小变化时拒绝继续）                   │    │
│  └─────────────────────────────────────────────────────────────┘    │
│                                                                      │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │                    最终输出文件                                │    │
│  │                                                               │    │
│  │  📄 filename.zip        (所有分片合并后的完整文件)              │    │
│  │                                                               │    │
│  │  合并完成后自动删除所有 .part 和 .info.txt 文件                │    │
│  └─────────────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────────────┘
```

## 文件类型汇总

| 文件 | 类型 | 生成方式 | 生命周期 | 清理时机 |
|------|------|---------|---------|---------|
| `proxies.txt` | 输入 | 用户手动创建 | 持久化 | 用户自行管理 |
| `filename.N.part` | 临时 | Worker 写入 | 运行时 | 合并成功后自动删除 |
| `filename.info.txt` | 临时 | main 写入 | 运行时 | 合并成功后自动删除 |
| `filename.zip` | 输出 | 合并产生 | 持久化 | 用户自行管理 |

## 配置方式

本项目**无配置文件**，全部通过 CLI 参数配置：

```bash
# 最小配置
mpd.exe -url "https://example.com/file.zip"

# 完整配置
mpd.exe -url "https://example.com/file.zip" \
        -output "D:\downloads\file.zip" \
        -proxy "D:\proxies.txt" \
        -max 50 \
        -part 20 \
        -retry 3 \
        -timeout 30 \
        -overwrite \
        -verbose
```

## 文件大小与分片关系

```
文件大小: 100 MB
分片大小: 10 MB (-part 10)
分片数量: 10
并发数:   30 (-max 30)
-----------------------------
实际并发: min(30, 10) = 10 个 Worker
每个 Worker 下载: 1 个分片 (10 MB)
总计速度 = 各代理速度之和
```
