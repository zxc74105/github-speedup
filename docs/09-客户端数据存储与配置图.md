# 视图09-客户端数据存储与配置图

## 覆盖范围
桌面应用的本地文件存储与配置

## 说明
数据持久化在主程序运行目录（AppDir），非 %APPDATA%。

## 存储全景

```
┌─────────────────────────────────────────────────────────────────────┐
│                    程序运行目录 (AppDir)                              │
│                                                                      │

│  │                    配置文件 (JSON)                             │    │
│  │                                                               │    │

│  │  📄 tasks.json             下载任务列表（持久化，重启恢复）      │    │
│  │  📄 proxy-records.json     代理成功记录（排行/速度历史）         │    │
│  │                                                               │    │
│  └─────────────────────────────────────────────────────────────┘    │
│                                                                      │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │                    输入文件                                    │    │
│  │                                                               │    │
│  │  📄 proxies.json          默认代理列表（29 个可用）            │    │
│  │  📄 proxies-all.json      全部 78 个代理标注                    │    │
│  │                                                               │    │
│  └─────────────────────────────────────────────────────────────┘    │
│                                                                      │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │                    运行时日志                                  │    │
│  │                                                               │    │
│  │  📄 proxy-access.log      HTTP 代理访问日志（每次启动清空）      │    │

│  │                    下载临时文件（下载输出目录）                    │    │
```

## 文件类型汇总

| 文件 | 类型 | 生成方式 | 生命周期 |
|------|------|---------|---------|
| `settings.json` | 配置 | ConfigAPI.SaveSettings() | 持久化 |
| `proxies-active.json` | 配置 | ProxyAPI 启动/测速时保存 | 持久化 |
| `tasks.json` | 数据 | DownloadAPI 创建/取消/删除时保存 | 持久化 |
| `proxy-records.json` | 数据 | 下载成功/失败时更新 | 持久化 |
| `proxies.json` | 输入 | 手动编辑 | 持久化 |
| `proxy-access.log` | 日志 | HTTP 服务每次请求 | 运行时，启动清空 |
| `filename.part.N` | 临时 | Worker 写入 | 合并后删除 |
| `filename` | 输出 | 合并产生 | 用户自行管理 |
