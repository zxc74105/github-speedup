# 视图09-客户端数据存储与配置图

## 覆盖范围
桌面应用的本地文件存储与配置

## 说明
数据持久化在主程序运行目录（AppDir），非 %APPDATA%。

## 文件类型汇总

| 文件 | 类型 | 生成方式 | 生命周期 |
|------|------|---------|---------|
| `settings.json` | 配置 | settings_page.py 保存 | 持久化 |
| `proxies-active.json` | 配置 | proxy_page.py 测速/启动时保存 | 持久化 |
| `tasks.json` | 数据 | download_page.py 创建/取消/删除时保存 | 持久化 |
| `proxy-records.json` | 数据 | 下载成功/失败时更新 (records.py) | 持久化 |
| `proxies.json` | 输入 | 手动编辑 | 持久化 |
| `proxy-access.log` | 日志 | HTTP 服务每次请求 | 运行时，启动清空 |
| `filename` | 输出 | legacy 并行分片 / aria2 兜底产生 | 用户自行管理 |
