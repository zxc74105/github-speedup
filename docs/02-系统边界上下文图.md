## 外部系统交互明细

| 外部系统 | 协议 | 鉴权方式 | 调用方 | 用途 |
|---------|------|---------|--------|------|
| HTTP/S 代理服务器 | HTTP/HTTPS | Basic Auth(可选) | Worker goroutine | 中转向源站的 Range 请求 |
| 目标文件服务器 | HTTPS | 无(直连) | 通过代理转发 | 获取文件 Content-Length 和分片内容 |
| 本地文件系统 | 文件 I/O | 无 | 文件合并器 | 读 proxies.txt、写 .part 分片、写输出文件 |

## 数据流方向

```
用户输入(-url) ──▶ 系统 ──▶ 外部代理 ──▶ 源站
                     │
                     ▼
                  .part 文件 ──▶ 合并 ──▶ 最终文件
```

## 边界规则

| 规则 | 说明 |
|------|------|
| 系统不存储任何代理凭证 | 代理认证信息仅存在于临时 HTTP Transport 中 |
| 系统不修改源站文件 | 仅通过 Range 请求读取，不写入 |
| 系统不依赖外部服务可用性 | 代理失败会自动切换，不阻塞整体流程 |
| 系统不保留临时文件 | 下载完成后自动删除 .part 和 .info.txt |
