## 外部系统交互明细

| 外部系统 | 协议 | 鉴权方式 | 调用方 | 用途 |
|---------|------|---------|--------|------|
| URL-prefix 反向代理服务器 | HTTPS | 无（直接 GET） | vipertls/requests/aria2c | 中转向源站的请求 |
| 目标文件服务器（GitHub） | HTTPS | 无（代理转发） | 通过代理 | 获取文件内容和分片 |
| 调用方（被动模式） | HTTP | 无 | 浏览器/curl/aria2 | 向 9090 发起加速请求 |
| 本地文件系统 | 文件 I/O | 无 | core/ 模块 | JSON 持久化、下载写入 |

## 边界规则

| 规则 | 说明 |
|------|------|
| 系统不存储任何代理凭证 | URL-prefix 代理均为公开服务，无需认证 |
| 系统在请求中模仿浏览器 | 所有 HTTP 请求携带完整 Chrome 浏览器头（UA/Accept/Sec-Fetch-*等） |
| 代理测试使用 vipertls | Chrome TLS 指纹，否则多数代理返回 403/HTML 验证页 |
| 代理失败自动切换 | 并行下载中分片失败自动换代理重试 |
| 不保留临时文件 | 并行分片直接写入最终文件，完成后校验大小 |
| GUI 与 HTTP 服务同时运行 | 可边用 GUI 下载边提供被动加速服务 |
