# 视图01-部署架构拓扑图

## 覆盖范围
整个项目（github-speedup PySide6 Qt6 桌面应用 + HTTP 加速服务）

## 说明
本项目为 **PySide6 Qt6 桌面应用**，Python 后端 + PySide6 Qt6 原生 UI，PyInstaller 打包为单 .exe 分发。同时提供 **HTTP 代理加速服务**（可选），支持被动加速下载。

## 支持的运行平台

| 平台 | 架构 | 构建标识 |
|------|------|---------|
| Windows | x86_64 | `github-speedup.exe` |
| Linux | x86_64 | `github-speedup` |
| macOS | ARM64 | `github-speedup` |

## 网络依赖

| 方向 | 协议 | 目标 | 用途 |
|------|------|------|------|
| 出站 | HTTPS | 代理服务器（URL-prefix 反向代理） | 通过代理向源站发 Range 请求下载文件 |
| 出站 | HTTPS | 代理服务器（主动测速） | 下载 speedtest.txt 测试延迟/速度 |
| 入站 | HTTP | 调用方浏览器/curl/aria2 | 被动加速模式接收请求 |
| 本地 | 文件系统 | JSON 配置文件 | 读取/写入持久化数据 |
| 本地 | 文件系统 | .part 分片 | 写入临时分片文件 |
| 本地 | 文件系统 | 输出目录 | 写入最终合并文件 |

## 部署方式

1. **下载二进制**：从 GitHub Releases 下载对应平台二进制
2. **源码编译**：`PyInstaller --onefile main.py`（需 Python 3.10+ + PySide6）
