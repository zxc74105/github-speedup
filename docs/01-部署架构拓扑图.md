# 视图01-部署架构拓扑图

## 覆盖范围
整个项目（multi-proxy-downloader CLI 工具）

## 说明
本项目为单二进制 CLI 工具，**无服务端/无分布式部署**，直接运行在用户本地环境。

## 支持的运行平台

| 平台 | 架构 | 构建标识 |
|------|------|---------|
| Windows | x86_64 | `multi-proxy-downloader-win-x64.exe` |
| Linux | x86_64 | `multi-proxy-downloader-linux-x64` |
| macOS | ARM64 | `multi-proxy-downloader-macos-arm64` |

## 网络依赖

| 方向 | 协议 | 目标 | 用途 |
|------|------|------|------|
| 出站 | HTTPS | 代理服务器列表 | 通过代理发送 Range 请求 |
| 出站 | HTTPS | 目标文件服务器 | 获取 Content-Length 和文件内容 |
| 本地 | 文件系统 | proxies.txt | 读取代理列表 |
| 本地 | 文件系统 | .part / .info.txt | 写入临时分片文件 |
| 本地 | 文件系统 | 输出目录 | 写入最终合并文件 |

## 部署方式

1. **直接下载二进制**：从 GitHub Releases 下载对应平台二进制
2. **源码编译**：`git clone && go build -ldflags "-w -s" -o mpd.exe`
3. **CI 自动构建**：GitHub Actions (build.yml) 自动编译并上传 artifacts
