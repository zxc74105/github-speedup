# 视图20-桌面端UI设计与交互规范

## 覆盖范围
桌面应用 UI 设计与实现

## 技术选型

| 选项 | 选择 | 原因 |
|------|------|------|
| UI 框架 | **Wails v2** | Go 原生桌面框架，单二进制分发 |
| 前端框架 | **React 19 + TypeScript** | 组件化开发 |
| UI 组件库 | **Ant Design 6** | 成熟桌面风格组件 |
| 图表 | **ECharts 6** | 实时速度趋势图 |
| 状态管理 | **Zustand 5** | 轻量，与 Go 后端消息对接简单 |
| 构建工具 | **Vite** | Wails 官方推荐 |
