# 视图20-桌面端UI设计与交互规范

## 覆盖范围
桌面应用 UI 设计与实现

## 技术选型

| 选项 | 选择 | 原因 |
|------|------|------|
| UI 框架 | **PySide6 (Qt6)** | Python Qt6 官方绑定 |
| UI 实现 | **QWidget 原生控件** | 原生风格，零 Web 依赖 |
| 表格 | **QTableWidget** | 原生表格控件 |
| 状态管理 | **Python 信号/槽** | 原生 Qt 事件机制 |
| 打包 | **PyInstaller --onefile** | 单 .exe 输出 |

## 后端 Python 调用接口

```
# 下载管理 (download_page.py → core/downloader.py + core/aria2_downloader.py)
create_task(url, save_dir) → TaskInfo
cancel_task(id) → None
delete_task(id) → None  (同时删除本地文件)

# 代理管理 (proxy_page.py → core/proxy_manager.py)
get_proxies() → list[ProxyItem]
test_all_proxies(callback) → None
test_proxy(domain) → ProxyTestResult
toggle_proxy(domain, enabled) → None
import_proxies(file_path) → int
export_proxies(file_path) → None
preflight_check() → PreflightResult
delete_proxies(domains) → None

# 设置管理 (settings_page.py → core/settings.py)
load_settings() → Settings
save_settings(s) → None
reset_settings() → Settings
pick_directory() → str
export_records() → str
clear_records() → None

# 代理记录 (download_page.py → core/records.py)
get_success_records() → list[ProxyRecord]
get_fail_records() → list[ProxyRecord]
clear_records() → None
```
