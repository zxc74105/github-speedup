# 视图20-桌面端UI设计与交互规范

## 覆盖范围
桌面应用程序（Windows/Mac/Linux）完整 UI 设计

## 技术选型

| 选项 | 选择 | 原因 |
|------|------|------|
| UI 框架 | **[Wails](https://wails.io)** v3 | Go 原生桌面框架；前端 HTML+CSS+JS 渲染；单二进制分发；跨平台 |
| 前端框架 | **React + TypeScript** | 生态丰富，组件化开发 |
| UI 组件库 | **Ant Design** 或 **shadcn/ui** | 成熟桌面风格组件，表格/表单/弹窗等开箱即用 |
| 图表 | **Chart.js** 或 **ECharts** | 实时速度趋势图 |
| 状态管理 | **Zustand** | 轻量，与 Go 后端消息对接简单 |
| 构建工具 | **Vite** | 快，Wails 官方推荐 |

### 下载任务列表

| 列 | 宽度 | 说明 |
|----|------|------|
| 文件名 | 弹性 | 文件名 + 保存文件夹子行（灰色小字）+ 保存到图标 |
| 大小 | 固定 90px | 文件总大小 |
| 进度 | 固定 140px | 进度条 + 已下载/百分比 |
| 速度 | 固定 100px | 实时速度 (Mbps) |
| 剩余 | 固定 80px | 预计剩余时间 |
| 状态 | 固定 100px | 状态点 + 文本 |

**任务行交互：**
- 单击选中 → 底部面板显示详情
- 双击 → 打开所在文件夹 (`runtime.OpenFolderDialog` / `shell.Open`)
- 右键 → 菜单（暂停/取消/重新下载/打开所在文件夹/更改保存文件夹...）
- 多选 → Ctrl+单击 / Shift+范围

**文件名字行示例：**
```
file.zip                                          ← 文件名（主行）
📁 D:\Downloads\github                             ← 保存文件夹（灰色小字子行）
```

### 底部详情面板

右侧 Tab 切换：

| Tab | 内容 |
|-----|------|
| 📋 详情 | 文件名、URL、保存文件夹（含 [📂打开] 按钮）、大小、分片数、已下载、总速度、代理切换次数 |
| ⚡ Worker | Worker 网格，每个显示 ID + 代理名 + 实时速度 |
| 📊 速度 | 实时折线图（最近 60s） |
| 📜 日志 | 按时间倒序的事件日志 |

### 持久化

所有设置存储为 JSON 文件，路径：

| 平台 | 路径 |
|------|------|
| Windows | `%APPDATA%/multi-proxy-downloader/settings.json` |
| macOS | `~/Library/Application Support/multi-proxy-downloader/settings.json` |
| Linux | `~/.config/multi-proxy-downloader/settings.json` |

### 设置 API

```go
// config.go
type ConfigAPI struct {}

func (c *ConfigAPI) GetSettings() Settings
func (c *ConfigAPI) SaveSettings(s Settings) error
func (c *ConfigAPI) ResetSettings() Settings        // 恢复默认并返回
func (c *ConfigAPI) ExportRecords() (string, error)  // 导出记录文件路径
func (c *ConfigAPI) ClearRecords() error
func (c *ConfigAPI) CheckUpdate() (string, bool)     // 新版本号 + 是否有更新
```

## 交互规范

### 按钮层级

```
主要操作: [开始下载] [保存] — 蓝色填充，最重要操作
次要操作: [暂停] [全部测速] — 灰色/线框，常规操作
危险操作: [取消] [删除] — 红色，需二次确认
链接操作: 导入 / 导出 — 文字链接，轻量操作
```

### 反馈机制

| 场景 | 反馈方式 |
|------|---------|
| 开始下载 | 按钮变为[下载中...] + 禁用 + 进入下载状态 |

## 代理健康检查与静默模式

### 设计目标

每次新建下载任务时，对所有代理进行**网络连通性 + 网速**检测，不达标的代理在当前任务中进入**静默模式**（不参与下载），但保留在列表中，下次新任务时重新检测。

### 检测流程

```
用户点击 [开始下载]
     │
     ▼
触发 代理预检 (ProxyPreflight)
     │
     ├── 对所有非静默代理（包括上次静默的）执行:
     │       ├── TCP 连接测试 (超时 3s)
     │       ├── HTTP HEAD 测试 (超时 5s)
     │       └── 速度基准测试 (下载 1MB 测试文件，限时 10s)
     │
     ├── 结果判定:
     │       ├── 延迟 > 500ms           → ⚠ 慢速 → 静默
     │       ├── 速度 < 1 Mbps          → ⚠ 过慢 → 静默
     │       ├── 连接失败               → ❌ 离线 → 静默
     │       └── 通过检测               → ✅ 可用 → 参与下载
     │
     ├── 更新代理状态:
     │       ├── 数据库记录本次检测延迟/速度/结果
     │       ├── 标记当前任务静默列表
     │       └── 前端实时推送检测进度
     │
     └── 进入下载流程 (仅使用 ✅ 可用代理)
```

### 静默模式规则

| 规则 | 说明 |
|------|------|
| 进入条件 | 延迟 > 500ms 或 速度 < 1 Mbps 或 连接失败 |
| 作用范围 | **仅当前下载任务**，不影响全局启用/禁用设置 |
| 下次任务 | 所有静默代理**重新检测**，不保留上次静默状态 |
| 前端显示 | 代理列表新增列「当前任务状态」= 静默中，底部栏显示「此任务静默: N」 |
| 手动覆盖 | 用户可在代理管理页手动取消「静默」标记，强制参与下次下载 |

### 状态机

```
┌──────────┐     新任务预检     ┌──────────┐
│  启用     │ ───────────────→ │  检测中   │
│  (全局)   │                  │ ⏳       │
└──────────┘                  └──────────┘
                                  │
                    ┌─────────────┴─────────────┐
                    │                           │
                    ▼                           ▼
              ┌──────────┐              ┌──────────┐
              │  可用     │              │  静默     │
              │ ✅ 参与下载│              │ ⏸ 不参与  │
              └──────────┘              └──────────┘
                    │                           │
                    │  新任务                    │  新任务
                    ▼                           ▼
              ┌──────────┐              ┌──────────┐
              │  重新检测  │              │  重新检测  │
              └──────────┘              └──────────┘
```

## 成功代理记录 (Success Proxy Records)

### 设计目标

记录每个代理**成功完成下载**的历史数据，按成功次数降序排列。使用越多的代理排名越靠前，帮助用户识别最可靠的代理。

### 数据模型

```json
{
  "domain": "gh.dpik.top",
  "successCount": 32,
  "totalBytes": 17179869184,
  "firstUsedAt": "2024-01-10T08:00:00Z",
  "lastUsedAt": "2024-01-15T14:30:00Z",
  "averageSpeed": 38.5,
  "failCount": 2,
  "speedHistory": [42.1, 38.5, 45.2, ...]
}
```

### 记录更新时机

| 时机 | 动作 |
|------|------|
| 分片下载成功 | 更新 successCount + 1，累加 totalBytes，记录速度 |
| 分片下载失败 | 更新 failCount + 1（失败次数过多会降级） |
| 整个文件下载完成 | 无额外操作（已在分片粒度记录） |
| 代理预检 | 更新延迟/速度字段，不修改 successCount |

### 排行规则

1. 按 `successCount` 降序排列（下载成功次数越多越靠前）
2. 并列时按 `averageSpeed` 降序
3. `successCount = 0` 的代理排在最后

### 无记录代理管理

| 操作 | 说明 |
|------|------|
| 筛选「无记录」 | 点击「选择无记录代理」自动勾选所有 `successCount = 0` 的代理 |
| 删除选中 | 🗑 批量删除勾选的代理（需二次确认「确定删除 N 个代理？」） |
| 右键删除 | 单个代理右键菜单 → [删除此代理] |
