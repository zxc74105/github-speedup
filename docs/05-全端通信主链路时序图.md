## 关键超时与重试时序

```
Worker 启动
   │
   ├──▶ Assign() 获取代理
   │       │
   │       ├──▶ DownloadPartialFile()
   │       │       │
   │       │       ├──▶ HTTP GET 通过代理 (Range)
   │       │       │       │
   │       │       │       ├──▶ 响应头到达 → 开始流式读取
   │       │       │       │       │
   │       │       │       │       ├──▶ 读取中 → 重置超时计时器
   │       │       │       │       │       │
   │       │       │       │       │       ├──▶ 超时 (无数据 > timeout 秒)
   │       │       │       │       │       │       → context cancel
   │       │       │       │       │       │       → Fail(proxy)
   │       │       │       │       │       │       → retry
   │       │       │       │       │       │
   │       │       │       │       │       └──▶ 读取完成
   │       │       │       │       │               → Release(proxy)
   │       │       │       │       │               → 分片完成
   │       │       │       │       │
   │       │       │       │       └──▶ HTTP 错误
   │       │       │       │               → 重试 (retry 次)
   │       │       │       │               → 仍失败 → Fail(proxy) → 新代理重试
   │       │       │       │
   │       │       │       └──▶ 全部重试耗尽
   │       │       │               → 分片下载失败，程序退出
   │       │       │
   │       │       └──▶ 成功 → Release(proxy) → 分片完成
   │       │
   │       └──▶ 所有分片完成 → Worker 退出
```

## 数据格式

| 步骤 | 数据 | 格式 |
|------|------|------|
| CLI 输入 | `-url` | `https://example.com/file.zip` |
| CLI 输入 | `-proxy` | 文本文件，每行一个代理 URL |
| 代理请求 | Range header | `Range: bytes=0-10485759` |
| 代理响应 | Content-Range | `Content-Range: bytes 0-10485759/104857600` |
| 临时文件 | filename.0.part | 二进制分片 |
| 元数据文件 | .info.txt | `文件名:文件大小` |
| 输出文件 | filename | 二进制合并结果 |
