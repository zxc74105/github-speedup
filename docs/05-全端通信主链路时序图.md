# 视图05-全端通信主链路时序图

## 覆盖范围
桌面应用完整下载链路（从 GUI 点击到文件落盘）

## 架构前提（2026-07-31 确认）
- 9090 HTTP 加速服务是给**外部工具**用的（浏览器/curl/aria2/脚本），不是给软件自身组件用的。
- 软件自身下载组件（aria2、Python 并行分片）**直接连接镜像代理网址**：
  `https://镜像域名/https://github.com/原始路径`，**不经过** `http://127.0.0.1:9090/...` 或 `http://127.0.0.1:6801/...`。
- 主路径：`downloader.py` `_legacy_download` 多代理并行分片；aria2 仅作兜底。
