## 技术演进路线图

```
当前状态 (v1.1.0)
  ├── ✅ 基础功能: 多代理并行分片下载
  ├── ✅ CLI 参数: -url, -output, -proxy, -max, -part, -retry, -timeout
  ├── ✅ 进度展示: progressbar (默认), verbose, JSON 三种模式
  ├── ✅ 速度/ETA: 滑动窗口实时计算
  ├── ✅ 超时控制: per-worker 不活动超时
  ├── ✅ CI/CD: GitHub Actions 自动构建 + Release
  └── ❌ 缺少: 单元测试、代理预检速度排序、Metalink 支持

短期规划
  ├── 🔲 代理预检: 下载前对代理列表测速并排序
  ├── 🔲 单元测试: 为 ProxyPool、文件操作添加 _test.go
  ├── 🔲 断点续传: 支持中断后从已有 .part 继续
  └── 🔲 代理分类: 按协议 (HTTP/HTTPS/SOCKS) 分组

长期展望
  ├── 🔲 Metalink 格式: aria2 兼容的多源下载描述文件
  ├── 🔲 RPC 控制: JSON-RPC 远程管理下载任务
  ├── 🔲 自动代理发现: 从公共代理列表自动获取/验证
  └── 🔲 Web UI: 浏览器管理下载任务
```
