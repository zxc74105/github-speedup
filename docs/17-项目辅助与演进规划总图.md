# 视图17-项目辅助与演进规划总图

## 版本历史

```
v1.0.0 → v1.1.0 → ... → 当前 (多轮迭代)

当前状态:
  ├── PySide6 Qt6 桌面应用 (PySide6 Qt6 原生 UI 前端 + Python 后端)
  ├── 下载组件直连镜像代理 (aria2 兜底 + Python 多代理并行分片)
  ├── HTTP 加速服务 (端口 9090, 仅外部工具调用)
  ├── 代理管理 (两阶段测速/预检/静默/导入/导出)
  ├── 任务持久化 (tasks.json, 重启恢复)
  ├── 代理成功记录 (proxy-records.json, 排行)
  ├── 访问日志 (proxy-access.log, 运行时)
  ├── vipertls Chrome TLS 指纹 (代理测速抗反爬)
  └── 完整浏览器头模拟 (Chrome 全头)
```

## 技术栈

| 层 | 技术 |
|----|------|
| 桌面框架 | PySide6 Qt6 |
| 后端语言 | Python 3.10+ |
| UI 组件库 | PySide6 Qt6 原生 |
| 状态管理 | Qt 信号/槽机制 |
| HTTP | requests + vipertls |
| 多源下载 | Python 并行分片 (主) + aria2c (兜底) |
| 构建 | PyInstaller --onefile build.spec |
