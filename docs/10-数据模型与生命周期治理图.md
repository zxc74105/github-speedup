│  TotalBytes     int64       // 文件大小              │

## 数据生命周期

### 1. ProxyItem 生命周期

```
加载 (NewProxyAPI)
  │ 读取 proxies-active.json → 不存在则从 proxies.json 加载默认
  ▼
用户操作
  │ TestAllProxies()  → 更新 Status/Latency/Speed
  │ ToggleProxy()     → 更新 Enabled
  ▼
持久化
  │ saveProxies() → 写入 proxies-active.json
```

### 2. TaskInfo 生命周期

```
创建 (CreateTask)
  │ 生成 ID → 加入 tasks 列表 → saveTasks()
  │ 启动后台 goroutine: StartBackgroundDownload
  ▼
下载中
  │ onProgress 回调 → 推送 download:progress 事件到前端
  ▼
完成
  │ 更新 Status/Downloaded/Speed/ETA → saveTasks()
  │ → 前端展示
  ▼
取消/删除
  │ CancelTask → CancelDownload(id) → saveTasks()
  │ DeleteTask → 删除文件 → saveTasks()
```

### 3. ProxyRecord 生命周期

```
首次成功 (RecordProxySuccess)
  │ 新建 ProxyRecord → 加入 successRecs
  ▼
后续成功
  │ SuccessCount++ / TotalBytes 累加 / AverageSpeed 更新
  ▼
持久化
  │ 每次更新立即 saveRecords() → proxy-records.json
  ▼
清理
  │ DeleteProxies() / ClearRecords()
```

## 数据校验规则

| 数据 | 校验点 | 方式 | 失败处理 |
|------|--------|------|---------|
| 代理域名 | 格式合法性 | IsValidProxyDomain() | 跳过该行 |
| 文件大小 | 获取 Content-Length | HEAD 请求 | 失败则任务失败 |
| 分片响应 | HTTP 状态码 | 206 / 200 | 失败则重试 |
| 分片内容 | 写入成功 | 写操作错误检查 | 失败则重试 |
