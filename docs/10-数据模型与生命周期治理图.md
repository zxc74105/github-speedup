# 视图10-数据模型与生命周期治理图

## 覆盖范围
所有核心数据结构（Python 后端）

## 核心数据模型

```
┌─────────────────────────────────────────────────────┐
│                    ProxyItem                         │
│  ─────────────────────────────                       │
│  Domain   str     # 域名（无 scheme）                │
│  Scheme   str     # "https" 或 "http"               │
│  Enabled  bool    # 是否启用                         │
│  Status   str     # "可用" / "不可用"                │
│  Latency  str     # "45 ms"                         │
│  Speed    str     # "1.7s" (body 下载耗时)           │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│                    TaskInfo                          │
│  ─────────────────────────────                       │
│  ID             int      # 任务 ID                  │
│  URL            str      # 下载链接                  │
│  FileName       str      # 文件名                   │
│  SaveDir        str      # 保存目录                 │
│  TotalBytes     int      # 文件大小                 │
│  Downloaded     int      # 已下载                   │
│  Speed          float    # 当前速度 (bps)           │
│  ETA            str      # 预计剩余时间              │
│  Status         str      # preparing/downloading    │
│                          # paused/completed/failed  │
│  Progress       float    # 进度百分比                │
│  CreatedAt      datetime # 创建时间                  │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│                    ProxyRecord                       │
│  ─────────────────────────────                       │
│  Domain        str        # 域名                    │
│  SuccessCount  int        # 成功下载次数             │
│  TotalBytes    int        # 累计下载字节             │
│  FailCount     int        # 失败次数                │
│  LastUsedAt    datetime   # 最近使用                │
│  SpeedHistory  list[float] # 速度历史（最近 N 次）   │
└─────────────────────────────────────────────────────┘
```

## 数据生命周期

### 1. ProxyItem 生命周期

```
加载 (proxy_manager 初始化)
  │ 读取 proxies-active.json → 不存在则从 proxies.json 加载默认
  ▼
用户操作
  │ test_all_proxies() → 更新 Status/Speed/Latency
  │ toggle_proxy()     → 更新 Enabled
  ▼
持久化
  │ _save_proxies() → 写入 proxies-active.json
```

### 2. TaskInfo 生命周期

```
创建 (download_page.py)
  │ 生成 ID → 加入 tasks 列表 → save_tasks()
  │ 启动后台线程: start_download()
  ▼
下载中
  │ on_progress 回调 → 通过 Qt 信号推送进度到 UI
  ▼
完成
  │ 更新 Status/Downloaded/Speed/ETA → save_tasks()
  ▼
取消/删除
  │ cancel_task → 设置 _cancelled Event → save_tasks()
  │ _delete_selected → 删除本地文件 → save_tasks()
```

### 3. ProxyRecord 生命周期

```
首次成功 (record_success)
  │ 新建 ProxyRecord → 加入 success_records
  ▼
后续成功
  │ SuccessCount++ / TotalBytes 累加
  ▼
失败
  │ FailCount++ (record_failure)
  ▼
持久化
  │ 每次更新立即 _save_records() → proxy-records.json
  ▼
清理
  │ clear_records() / delete_proxies()
```

## 数据校验规则

| 数据 | 校验点 | 方式 | 失败处理 |
|------|--------|------|---------|
| 代理域名 | 格式合法性 | URL 解析 | 跳过该行 |
| 文件大小 | 获取 Content-Length | HEAD 请求 | 失败则任务失败 |
| 分片响应 | HTTP 状态码 | 206 / 200 | 失败则重试 |
| 分片内容 | 写入成功 | 写操作错误检查 | 失败则重试 |
