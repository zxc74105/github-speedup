# 视图12-安全架构视图

## 覆盖范围
桌面应用的安全模型

## 安全架构总图

```
┌─────────────────────────────────────────────────────────────────────┐
│                  github-speedup 安全边界                              │
│                                                                      │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │                  不可信区域（外部网络）                           │    │
│  │                                                                 │    │
│  │  URL-prefix 反向代理服务器 (HTTPS)                              │    │
│  │      │                                                          │    │
│  │      │ 代理能看到请求路径和 Range 头                             │    │
│  │      │ 所有出站请求携带完整浏览器头                              │    │
│  │      │ (UA/Accept/Accept-Language/Sec-Fetch-*...)              │    │
│  │      │ 绕过反爬/人机验证                                          │    │
│  │      ▼                                                          │    │
│  │  目标文件服务器 (GitHub Releases)                                │    │
│  └─────────────────────────────────────────────────────────────┘    │
│                           │                                          │
│                           │ HTTPS (源站)                             │
│                           │ HTTP (局域网)                            │
│                           ▼                                          │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │                  可信区域（用户本地）                            │    │
│  │                                                                 │    │
│  │  TLS 证书验证: 默认跳过 (InsecureSkipVerify=true)               │    │
│  │  原因: 代理服务器常使用自签名证书                                │    │
│  │  风险: MITM 攻击                                                │    │
│  │                                                                 │    │
│  │  HTTP 加速服务: 端口 9090，默认允许远程访问                       │    │
│  │  风险: 局域网内任意设备可使用代理                                 │    │
│  │                                                                 │    │
│  │  本地文件安全:                                                  │    │
│  │  - 并行分片直接写入最终文件，完成后校验大小                                  │    │
│  │  - JSON 持久化文件仅含域名/速度/任务记录，无敏感信息              │    │
│  │  - 请求头模拟浏览器（无 Cookie/无认证信息泄露）                    │    │
│  └─────────────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────────────┘
```

## 传输安全

| 环节 | 协议 | TLS | 证书验证 |
|------|------|-----|---------|
| 本机 → 代理 | HTTPS | 强制 | 跳过 |
| 代理 → 源站 | HTTPS | 强制 | 由代理决定 |
| HTTP 加速服务 | HTTP | 无 | — |

## 模拟浏览器请求头

所有出站 HTTP 请求携带完整 Chrome 请求头，包括：

```
User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36
Accept: text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8
Accept-Language: zh-CN,zh;q=0.9,en;q=0.8
Accept-Encoding: gzip, deflate, br
Sec-Ch-Ua: "..."
Sec-Ch-Ua-Mobile: ?0
Sec-Ch-Ua-Platform: "Windows"
Sec-Fetch-Dest: document
Sec-Fetch-Mode: navigate
Sec-Fetch-Site: none
Sec-Fetch-User: ?1
Upgrade-Insecure-Requests: 1
DNT: 1
```

## 安全风险与缓解

| 风险 | 等级 | 说明 | 缓解 |
|------|------|------|------|
| MITM 攻击 | ⚠️ 中 | TLS 证书验证跳过 | 仅在可信网络使用 |
| HTTP 服务暴露 | ⚠️ 中 | 9090 端口可被局域网调用 | 默认允许远程，可用于手机/其他电脑 |
| 代理记录流量 | ⚠️ 低 | 代理能看到下载路径 | 代理均为公开 GitHub 加速服务 |
