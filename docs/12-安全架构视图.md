# 视图12-安全架构视图（简化版）

## 覆盖范围
CLI 工具的认证、传输安全、敏感数据处理

```

│  │      │                           │                               │    │
```

## 传输安全

| 环节 | 协议 | TLS | 证书验证 | 备注 |
|------|------|-----|---------|------|
| 本地 → 代理 | HTTP/HTTPS | 可选 | 默认跳过 | 自签名证书常见 |
| 代理 → 源站 | HTTPS | 强制 | 由代理决定 | 不在本工具控制范围 |
| 本地 → 源站(直连) | HTTPS | 强制 | 默认跳过 | 用于 GetFileInfo |

## 认证方式

| 认证类型 | 支持方式 | 配置位置 |
|---------|---------|---------|
| 代理 Basic Auth | `http://user:pass@host:port` | proxies.txt |
| 代理 Bearer Token | 不支持 | - |
| 目标服务器认证 | 不支持 | - |
| 客户端证书 | 不支持 | - |

## 敏感数据清单

| 数据类型 | 存在位置 | 持久化 | 清理方式 |
|---------|---------|--------|---------|
| 代理认证凭据 | proxies.txt (文件) | ✅ 持久化 | 用户手动删除 |
| 代理认证凭据 | 进程内存 (Transport) | ❌ 运行时 | Go GC 回收 |
| 代理认证凭据 | HTTP Header (网络) | ❌ 一次性 | 请求结束 |
| 下载文件内容 | .part 文件 (磁盘) | ❌ 临时 | 合并后自动删除 |
| 文件元数据 | .info.txt (磁盘) | ❌ 临时 | 完成后自动删除 |

## 安全风险与缓解措施

| 风险 | 等级 | 说明 | 缓解 |
|------|------|------|------|
| MITM 攻击 | ⚠️ 中 | TLS 证书验证跳过 | 仅在可信网络使用；或修改代码启用验证 |
| 凭据泄露 | ⚠️ 中 | proxies.txt 含明文密码 | 设置文件权限 600；使用后清除 |
| 代理记录流量 | ⚠️ 低 | 代理能看到下载内容 | 使用 HTTPS 代理；下载内容本身非敏感 |
| 文件完整性 | ✅ 低 | 分片合并后校验总大小 | 已实现大小校验 |
| CSRF/RCE | ✅ 无风险 | CLI 工具无服务端接口 | 不适用 |

## 安全配置建议

```bash
# 1. 限制 proxies.txt 访问权限 (Linux/Mac)
chmod 600 proxies.txt

# 2. 使用 HTTPS 代理而非 HTTP
# proxies.txt 中写:
# https://proxy.example.com:443

# 3. 下载完成后清除代理列表
rm proxies.txt

# 4. 使用完后清空 shell 历史
history -c
```
