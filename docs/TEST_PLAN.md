# 测试计划

## 测试环境
- OS: Windows
- Python 3.12+ / 独立 exe
- PySide6
- 打包: PyInstaller (build.spec)
- 目标: GitHub Multi-Proxy Downloader

## 测试用例

| TC | 名称 | 步骤 | 预期 |
|----|------|------|------|
| TC001 | 应用启动 | 启动 exe | 窗口显示，无崩溃 |
| TC002 | 代理列表加载 | 打开代理页 | 显示代理列表 |
| TC003 | 全部测速 | 点击全部测速 | 30 线程并行测速，实时刷新 |
| TC004 | 代理预检 | 点击代理预检 | 显示可用/不可用数量 |
| TC005 | 代理记录 | API 或 GUI 下载后检查记录表 | 记录显示成功次数 |
| TC006 | 新建任务 | 输入 URL，点确定 | 任务出现在列表 |
| TC007 | 下载进度 | 下载中观察进度条 | 进度条+速度+大小实时更新，大文件有中间进度 |
| TC008 | 取消任务 | 选任务点取消 | 任务取消 |
| TC009 | 删除任务 | 选任务点删除 | 任务移除，本地文件删除 |
| TC010 | 筛选 | 点全部/下载中/已完成/失败 | 列表按状态筛选 |
| TC011 | 设置保存 | 改设置后保存 | 重启后设置保留 |
| TC012 | 清空记录 | 点清空记录 | 记录表清空，无确认框 |
| TC013 | HTTP API | curl http://127.0.0.1:9090/... | 返回文件内容（外部工具专用） |
| TC014 | 任务持久化 | 创建任务后重启 | 任务保留（标记暂停） |
| TC015 | 大文件并行分片 | 下载 137MB 安装包 | 15s 内出进度，中间值逐步增长 |
