# 视图13-客户端分层调用链图

## 覆盖范围
桌面应用完整调用链（从用户操作到网络请求和磁盘写入）

## 四层调用架构

```
┌─────────────────────────────────────────────────────────────────────┐
│  第1层: UI 层 (PySide6 Qt6 原生 UI)                                  │
│  ───────────────────────────────────────                              │
│                                                                      │
│  DownloadPage          ProxyPage             SettingsPage            │
│    │ 用户点击[创建任务]  │ 用户点击[全部测速]    │ 用户点击[保存]     │
│    ▼                    ▼                      ▼                     │
│  Python 后端 API: DownloadAPI.create_task()                         │
│  Python 后端 API: ProxyAPI.test_all_proxies()                       │
│  Python 后端 API: ConfigAPI.save_settings()                         │
│                                                                      │
│  实时更新: Qt 信号/槽 'progress_updated' 监听后端推送的进度           │
│                                                                      │
└──────────────────────────┬───────────────────────────────────────────┘
                           │ Python 直接调用
┌──────────────────────────┼───────────────────────────────────────────┐
│  第2层: API 层 (gui/ 回调桥接)                                        │
│  ───────────────────────────────────────                              │
│                                                                      │
│  DownloadPage.create_task() → 保存任务 + 启动后台线程                 │
│  │                                                                   │
│  ├── 生成 TaskInfo, 加入 tasks, save_tasks()                         │
│  ├── 启动 threading.Thread                                           │
│  │   └── 调用 core.downloader.start_download(...)                    │
│  │      ├── 传入回调: record_success / record_failure / on_progress  │
│  │      └── 完成后更新 TaskInfo → save_tasks()                       │
│  └── 立即返回 TaskInfo (异步)                                        │
│                                                                      │
│  ProxyPage.test_all() → 遍历代理 → proxy_manager.test_single()       │
│                                                                      │
│  proxy_server.handle_proxy() → 遍历代理 → proxy_request()            │
│                                                                      │
└──────────────────────────┬───────────────────────────────────────────┘
                           │
┌──────────────────────────┼───────────────────────────────────────────┐
│  第3层: 核心引擎层 (core/)                                             │
│  ───────────────────────────────────────                              │
│                                                                      │
│  start_download()                                                    │
│    ├── 加载代理列表 (load_active_proxies)                             │
│    ├── HEAD 请求获取文件大小 (get_file_size_via_any_proxy)            │
│    ├── 计算分片 (4MB each)                                           │
│    ├── 创建 queue.Queue + 启动 20 个 Worker 线程                     │
│    │   └── 每个 Worker:                                              │
│    │       ├── 从任务队列接收 part_job                                │
│    │       ├── 构建 HTTP GET 请求 (Range + 完整浏览器头)              │
│    │       ├── 通过 requests / urllib3 发送                          │
│    │       ├── 流式读取响应写入 .part.N 文件                          │
│    │       └── 结果发送到结果队列                                     │
│    ├── 收集结果 + 重试失败分片                                        │
│    ├── 合并分片 (按顺序读取 .part → 写入最终文件)                     │
│    └── 记录最优代理到 record_proxy_success                            │
│                                                                      │
└──────────────────────────┬───────────────────────────────────────────┘
                           │
┌──────────────────────────┼───────────────────────────────────────────┐
│  第4层: 网络 + 文件 I/O 层                                            │
│  ───────────────────────────────────────                              │
│                                                                      │
│  网络操作:                                                           │
│  ├── requests.Session (共享连接池)                                    │
│  │   ├── TLS: verify=False (跳过证书验证)                             │
│  │   ├── Timeout: connect=5s, read=30s                               │
│  │   └── 浏览器头: 完整 Chrome 头                                    │
│  ├── HTTP 请求 → 代理服务器 → 源站                                    │
│  └── 请求头: 完整 Chrome 浏览器头                                     │
│                                                                      │
│  文件操作:                                                           │
│  ├── 读: proxies.json / proxies-active.json / settings.json           │
│  ├── 写: .part.* 分片文件 / tasks.json / proxy-records.json          │
│  └── 删: 合并完成后删除 .part.*                                       │
└──────────────────────────────────────────────────────────────────────┘
```

## 调用链数据流（主动下载）

```
用户输入 URL
     │
     ▼
DownloadPage (设置 URL → 点击[开始下载])
     │ create_task({url, save_dir, concurrency, ...})
     ▼
DownloadAPI.create_task()
     ├── 保存任务到 tasks.json
     └── 启动线程 → core.start_download()
             │
             ├── load_active_proxies() → ["https://gh-proxy.com", ...]
             ├── HEAD 获取 Content-Length
             ├── 计算分片: part_size=4MB, 总 N 部分
             ├── queue.Queue → 20 Workers
             │       │
             │       ├── Worker0: GET proxyA/{url} Range:bytes=0-4194303
             │       │   → 写入 file.part.0
             │       ├── Worker1: GET proxyB/{url} Range:bytes=4194304-8388607
             │       │   → 写入 file.part.1
             │       └── ...
             │
             ├── 收集 results
             ├── 重试失败分片（换不同代理）
             ├── 合并 .part.* → 最终文件
             └── 记录 best_proxy → record_proxy_success
```

## 被动加速调用链

```
浏览器: GET http://127.0.0.1:9090/https://github.com/.../file.zip
     │
     ▼
proxy_server.handle_proxy(request)
     │ 解析目标 URL (修复浏览器 // 规范化)
     │
     ├── 遍历可用代理列表 (Status=active, Enabled=true)
     │       │
     │       ├── proxy_request() → GET {proxy_url}/{target_url}
     │       │   ├── 透传原始请求头
     │       │   ├── 发送请求
     │       │   ├── 检查响应 (Status>=400 skip, text/html skip)
     │       │   └── 成功 → 写入响应流 → 返回
     │       │
     │       └── 失败 → 日志 FAIL → 尝试下一个代理
     │
     └── 全部失败 → 502 Bad Gateway
```
