# 视图13-客户端分层调用链图

## 覆盖范围
桌面应用完整调用链（从用户操作到网络请求和磁盘写入）

## 四层调用架构

```
┌─────────────────────────────────────────────────────────────────────┐
│  第1层: UI 层 (React 前端)                                            │
│  ───────────────────────────────────────                              │
│                                                                      │
│  DownloadPage.tsx          ProxyPage.tsx         SettingsPage.tsx    │
│    │ 用户点击[创建任务]      │ 用户点击[全部测速]    │ 用户点击[保存]   │
│    ▼                        ▼                      ▼                │
│  window.go.bindings.DownloadAPI.CreateTask()                          │
│  window.go.bindings.ProxyAPI.TestAllProxies()                        │
│  window.go.bindings.ConfigAPI.SaveSettings()                         │
│                                                                      │
│  实时更新: EventsOn('download:progress') 监听 Go 推送的进度           │
│                                                                      │
└──────────────────────────┬───────────────────────────────────────────┘
                            │ Wails Runtime Bridge
┌──────────────────────────┼───────────────────────────────────────────┐
│  第2层: API 绑定层 (bindings/)                                         │
│  ───────────────────────────────────────                              │
│                                                                      │
│  DownloadAPI.CreateTask()  → 保存任务 + 启动后台 goroutine           │
│  │                                                                   │
│  ├── 生成 TaskInfo, 加入 tasks, saveTasks()                          │
│  ├── 启动 goroutine                                                  │
│  │   └── 调用 core.StartBackgroundDownload(...)                     │
│  │      ├── 传入回调: recordSuccess / recordFailure / onProgress     │
│  │      └── 完成后更新 TaskInfo → saveTasks()                       │
│  └── 立即返回 TaskInfo (异步)                                        │
│                                                                      │
│  ProxyAPI.TestAllProxies() → 遍历代理 → testSingleProxy()            │
│                                                                      │
│  HTTPService.handleProxy() → 遍历代理 → proxyRequest()               │
│                                                                      │
└──────────────────────────┬───────────────────────────────────────────┘
                            │
┌──────────────────────────┼───────────────────────────────────────────┐
│  第3层: 核心引擎层 (core/)                                              │
│  ───────────────────────────────────────                              │
│                                                                      │
│  StartBackgroundDownload()                                           │
│    ├── 加载代理列表 (loadActiveProxies)                               │
│    ├── HEAD 请求获取文件大小 (getFileSizeViaAnyProxy)                 │
│    ├── 计算分片 (4MB each)                                           │
│    ├── 创建 job channel + 启动 20 个 Worker goroutine               │
│    │   └── 每个 Worker:                                              │
│    │       ├── 从 jobCh 接收 partJob                                  │
│    │       ├── 构建 HTTP GET 请求 (Range + 完整浏览器头)              │
│    │       ├── 通过 SharedTransport.RoundTrip 发送                   │
│    │       ├── 流式读取响应写入 .part.N 文件                          │
│    │       └── 结果发送到 results channel                             │
│    ├── 收集结果 + 重试失败分片                                        │
│    ├── 合并分片 (按顺序读取 .part → 写入最终文件)                     │
│    └── 记录最优代理到 RecordProxySuccess                              │
│                                                                      │
└──────────────────────────┬───────────────────────────────────────────┘
                            │
┌──────────────────────────┼───────────────────────────────────────────┐
│  第4层: 网络 + 文件 I/O 层                                             │
│  ───────────────────────────────────────                              │
│                                                                      │
│  网络操作:                                                           │
│  ├── SharedTransport (自定义 Transport)                              │
│  │   ├── TLS: InsecureSkipVerify                                     │
│  │   ├── Timeout: 5s 连接 / 5s TLS / 5s 响应头                      │
│  │   ├── KeepAlive: 30s                                              │
│  │   └── MaxIdleConns: 100                                          │
│  ├── HTTP 请求 → 代理服务器 → 源站                                    │
│  └── 请求头: 完整 Chrome 浏览器头                                     │
│                                                                      │
│  文件操作:                                                           │
│  ├── 读: proxies.json / proxies-active.json / settings.json           │
│  ├── 写: .part.* 分片文件 / tasks.json / proxy-records.json          │
│  └── 删: 合并完成后删除 .part.*                                       │
└──────────────────────────────────────────────────────────────────────┘
```

## 调用链数据流（主动下载）

```
用户输入 URL
     │
     ▼
DownloadPage.tsx (设置 URL → 点击[开始下载])
     │ CreateTask({url, saveDir, concurrency, ...})
     ▼
DownloadAPI.CreateTask()
     ├── 保存任务到 tasks.json
     └── 启动 goroutine → core.StartBackgroundDownload()
             │
             ├── loadActiveProxies() → ["https://gh-proxy.com", ...]
             ├── HEAD 获取 Content-Length
             ├── 计算分片: partSize=4MB, 总 N 部分
             ├── jobCh → 20 Workers
             │       │
             │       ├── Worker0: GET proxyA/{url} Range:bytes=0-4194303
             │       │   → 写入 file.part.0
             │       ├── Worker1: GET proxyB/{url} Range:bytes=4194304-8388607
             │       │   → 写入 file.part.1
             │       └── ...
             │
             ├── 收集 results
             ├── 重试失败分片（换不同代理）
             ├── 合并 .part.* → 最终文件
             └── 记录 bestProxy → RecordProxySuccess
```

## 被动加速调用链

```
浏览器: GET http://127.0.0.1:9090/https://github.com/.../file.zip
     │
     ▼
HTTPService.handleProxy(w, r)
     │ 解析目标 URL (修复浏览器 // 规范化)
     │
     ├── 遍历可用代理列表 (Status=active, Enabled=true)
     │       │
     │       ├── proxyRequest() → GET {proxyURL}/{targetURL}
     │       │   ├── 透传原始请求头
     │       │   ├── 发送请求
     │       │   ├── 检查响应 (Status>=400 skip, text/html skip)
     │       │   └── 成功 → 写入响应流 → 返回
     │       │
     │       └── 失败 → 日志 FAIL → 尝试下一个代理
     │
     └── 全部失败 → 502 Bad Gateway
```
