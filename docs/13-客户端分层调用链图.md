# 视图13-客户端分层调用链图

## 覆盖范围
桌面应用完整调用链（从用户操作到网络请求和磁盘写入）

│  ───────────────────────────────────────                              │

│  DownloadPage          ProxyPage             SettingsPage            │

│  ───────────────────────────────────────                              │

## 调用链数据流（主动下载）

```
用户输入 URL
     │
     ▼
DownloadPage (设置 URL → 点击[开始下载])
     │ create_task({url, save_dir, concurrency, ...})
     ▼
start_download() / start_background_download()
     ├── 加载并排序代理 (按 speed) → ["https://gh-proxy.com", ...]
     ├── 后台探测 Content-Range (Range 0-0 + identity)
     ├── 主路径 [legacy 并行分片] _legacy_download()
     │   ├── 预分配文件 → 分片 (max(4MB, total/8))
     │   ├── 每片一个线程直连镜像:
     │   │   └── GET {镜像域名}/{url} Range:bytes=X-Y
     │   │       → seek(X) 写入 → confirmed_bytes +=
     │   ├── 分片失败 → 换下一个代理重试
     │   └── 全部完成 → 校验大小 → 记录代理
     │
     └── 兜底 [aria2 模式] _aria2_download() (legacy 失败后)
         ├── build_mirror_urls 直连镜像 (不经本地代理)
         ├── aria2c addUri URL1 URL2 URL3 ...
         ├── 轮询进度 → on_progress
         └── 完成 → tellStatus → 解析 URIs → record
```

## 被动加速调用链

```
浏览器: GET http://127.0.0.1:9090/https://github.com/.../file.zip
     │
     ▼
proxy_server.handle_proxy(request)
     │ 解析目标 URL (修复浏览器 // 规范化)
     │
     ├── 遍历可用代理列表 (Status="可用", Enabled=true)
     │       │
     │       ├── proxy_request() → GET {proxy_url}/{target_url}
     │       │   ├── 透传原始请求头
     │       │   ├── 发送请求
     │       │   ├── 检查响应 (Status>=400 skip, text/html skip)
     │       │   └── 成功 → 写入响应流 → 返回
     │       │
     │       └── 失败 → 日志 FAIL → 尝试下一个代理
     │
     └── 全部失败 → 502 Bad Gateway
```
