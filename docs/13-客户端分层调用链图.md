# 视图13-客户端分层调用链图

## 覆盖范围
CLI 工具内部完整调用链

## 四层调用架构

```
┌──────────────────────────────────────────────────────────────────────┐
│  第1层: CLI 入口层 (main.go)                                         │
│  ───────────────────────────────────────                              │
│                                                                      │
│  职责: 参数解析 → 任务编排 → 进度展示 → 结果处理                       │
│                                                                      │
│  main()                                                              │
│   ├─ 1. flag.Parse(&url, &output, &proxy, &max, ...)                 │
│   ├─ 2. ReadLines(proxyFile)  ──▶ []string                          │
│   ├─ 3. NewProxyPool(proxies)  ──▶ *ProxyPool                       │
│   ├─ 4. GetFileInfo(url, proxy)  ──▶ (fileName, contentLength)      │
│   ├─ 5. DivideFileIntoParts(length, partSize)  ──▶ []FilePart       │
│   ├─ 6. PrepareOutputPath(path)  ──▶ workDir, absPath               │
│   ├─ 7. SaveContentLength(workDir, name, length)  ──▶ .info.txt     │
│   ├─ 8. 创建 partsChan, 启动 Worker goroutine × maxConcurrent      │
│   │      │  (每个 Worker 独立 goroutine)                              │
│   │      ├── Worker 内部:                                            │
│   │      │  ├── for part := range partsChan                         │
│   │      │  ├── pool.Assign(workerID)  → proxyURL                   │
│   │      │  ├── DownloadPartialFile(url, proxy, part, ...)          │
│   │      │  │   ├── HTTP GET Range: bytes=Start-End                 │
│   │      │  │   ├── 流式写入 filename.N.part                        │
│   │      │  │   └── 返回 (downloadedBytes, error)                   │
│   │      │  ├── success → pool.Release(workerID)                    │
│   │      │  └── fail → pool.Fail(workerID) → 重试                   │
│   │      └── 所有 Worker 退出后继续                                  │
│   ├─ 9. ConcatenateFiles(outputPath, workDir)  ──▶ 合并文件          │
│   │      ├── 按顺序读取 0.part, 1.part, ... N.part                   │
│   │      └── 追加写入最终文件, 删除 .part 文件                       │
│   ├─10. 验证最终文件大小 == contentLength                            │
│   └─11. os.Remove(.info.txt)                                        │
│                                                                      │
└──────────────────────────┬───────────────────────────────────────────┘
                           │
                           ▼
┌──────────────────────────────────────────────────────────────────────┐
│  第2层: 代理管理层 (proxy.go)                                         │
│  ───────────────────────────────────────                              │
│                                                                      │
│  职责: 代理生命周期管理、故障切换、并发安全                             │
│                                                                      │
│  ProxyPool {                                                        │
│    queue    []string         // 可用代理 FIFO 队列                    │
│    assigned map[string]string // workerID → proxyURL                 │
│    mu       sync.Mutex       // 所有方法均加锁                        │
│  }                                                                   │
│                                                                      │
│  NewProxyPool(proxies)                                               │
│    └── shuffle → queue                                               │
│                                                                      │
│  Assign(workerID) → proxyURL                                         │
│    ├── Lock()                                                       │
│    ├── assigned[id] 已存在? → 返回已分配代理                           │
│    ├── 从 queue 头部取出 → assigned[id]=proxy                       │
│    └── Unlock() → return proxy                                      │
│                                                                      │
│  Release(workerID)                                                   │
│    ├── Lock()                                                       │
│    ├── 从 assigned 取出 proxy                                       │
│    ├── 放回 queue 头部 (优先重用)                                    │
│    └── Unlock()                                                     │
│                                                                      │
│  Fail(workerID) → newProxyURL                                       │
│    ├── Lock()                                                       │
│    ├── 从 assigned 取出 proxy                                       │
│    ├── 放回 queue 尾部 (轮转)                                       │
│    ├── errorCount++                                                 │
│    ├── 从 queue 头部取新代理 → assigned[id]=newProxy                │
│    └── Unlock() → return newProxy                                   │
│                                                                      │
└──────────────────────────┬───────────────────────────────────────────┘
                           │
                           ▼
┌──────────────────────────────────────────────────────────────────────┐
│  第3层: HTTP 请求层 (utils.go)                                        │
│  ───────────────────────────────────────                              │
│                                                                      │
│  职责: HTTP Range 请求发送、响应处理、超时控制                          │
│                                                                      │
│  GetFileInfo(fileURL, proxyURL) → (name, length, error)             │
│    ├── HEAD request (通过代理)                                       │
│    ├── 解析 Content-Length, Content-Disposition                     │
│    └── 若 HEAD 无 Content-Length → Range: bytes=0-0 (206 探测)     │
│                                                                      │
│  DownloadPartialFile(url, proxy, part, outputPath, ...) → error     │
│    ├── 创建 http.Client (Transport 配置 proxy)                      │
│    ├── 创建 context.WithCancel                                      │
│    ├── 创建 GET request (Range: bytes=Start-End)                    │
│    ├── Do(request) → response                                       │
│    ├── 检查 status (期望 206)                                       │
│    ├── 创建 progressReader (包装 Body, 超时检测)                     │
│    ├── 创建 trackReader (包装 progressReader, 字节计数)              │
│    ├── io.Copy (trackReader → .part file)                           │
│    ├── 更新 onProgress (回调上报进度)                                │
│    └── 返回 (下载字节数, 错误)                                       │
│                                                                      │
└──────────────────────────┬───────────────────────────────────────────┘
                           │
                           ▼
┌──────────────────────────────────────────────────────────────────────┐
│  第4层: 文件 I/O 层 (utils.go)                                        │
│  ───────────────────────────────────────                              │
│                                                                      │
│  职责: 文件读写、分片管理、合并输出                                     │
│                                                                      │
│  DivideFileIntoParts(totalLength, partSizeBytes) → []FilePart       │
│    ├── 计算分片数量 = ceil(total / partSize)                         │
│    ├── 遍历生成 FilePart{Number, Start, End}                        │
│    └── 末分片 End = totalLength                                     │
│                                                                      │
│  SaveContentLengthToFile(workDir, fileName, contentLength)          │
│    ├── 写入 workDir/fileName.info.txt                               │
│    └── 若已存在 → 比较大小 → 不一致则返回错误                          │
│                                                                      │
│  ConcatenateFiles(outputPath, workDir)                              │
│    ├── 按 Number 顺序读取 .N.part 文件                               │
│    ├── 逐个追加写入最终文件                                          │
│    └── 删除所有 .part 文件                                           │
│                                                                      │
└──────────────────────────────────────────────────────────────────────┘
```

## 调用链数据流

```
用户输入
   │
   ▼
┌─────────────┐     proxies.txt     ┌──────────────┐
│  CLI 参数    │────────────────────▶│  ProxyPool    │
│  (url,max..) │                     │  queue/shuffle│
└──────┬──────┘                     └──────┬───────┘
       │                                   │
       ▼                                   ▼
┌──────────────┐                  ┌──────────────────┐
│  GetFileInfo  │                  │  Assign(workerID) │
│  HEAD → length│                  │  → proxyURL      │
└──────┬───────┘                  └────────┬─────────┘
       │                                   │
       ▼                                   ▼
┌──────────────┐                  ┌──────────────────┐
│DivideIntoParts│                  │ DownloadPartial  │
│→ []FilePart   │                  │ File(url,proxy,  │
└──────┬───────┘                  │  Range,partPath) │
       │                          └────────┬─────────┘
       │                                   │
       ▼                                   ▼
┌──────────────┐                  ┌──────────────────┐
│  Worker Pool  │◄────────────────│  HTTP GET Range   │
│  (goroutines)  │                 │  → 206 Partial    │
└──────┬───────┘                  │  → .N.part 文件    │
       │                          └──────────────────┘
       ▼
┌──────────────┐
│Concatenate   │
│Files(.part→  │
│ 最终文件)     │
└──────────────┘
```
