## 关键设计模式

| 模式 | 实现位置 | 说明 |
|------|---------|------|
| **Worker Pool** | core/downloader.go | buffered channel + goroutine 限并发 |
| **异步任务** | bindings/download.go:CreateTask | 立即返回 TaskInfo，后台 goroutine 下载 |
| **回调** | core/downloader.go:StartBackgroundDownload | recordSuccess/recordFailure/onProgress 回调 |
| **Proxy Rotation** | core/downloader.go | 失败的 part 用不同代理重试 |
| **滑动窗口测速** | core/downloader.go:calcSpeed | 最近 10s 速度采样计算 |
