```

 │     ├── main_window.py     主窗口布局与页面切换

  │     ├── downloader.py      多代理并行分片下载 (threading 分片)
  │     ├── aria2_downloader.py aria2c 直连镜像子进程管理 + 代理记录
  │     ├── proxy_manager.py   代理列表加载/两阶段测速/静默管理
  │     ├── local_viper_proxy.py 遗留 vipertls 本地代理（组件不再使用）

 │
 └──▶ github_speedup/server/ (HTTP 服务层)
       └── proxy_server.py    HTTP 加速服务 (ThreadingHTTPServer)
```

## 关键设计模式

| 模式 | 实现位置 | 说明 |
|------|---------|------|
| **并行分片下载** | core/downloader.py:_legacy_download | 每片一个线程直连镜像，Range 分片 seek 写入 |
| **异步任务** | gui/download_page.py:create_task | 立即返回 TaskInfo，后台线程下载 |
| **回调** | core/downloader.py:start_background_download | record_success/record_failure/on_progress 回调 |
| **Proxy Rotation** | core/downloader.py | 失败的分片用下一个代理重试 |
| **两阶段测速** | core/proxy_manager.py | vipertls 连通 + requests 体下载速度 |
| **vipertls 线程本地** | core/utils.py:get_viper() | threading.local() 每线程独立 TLS 客户端 |
