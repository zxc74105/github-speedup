## 模块职责划分与依赖方向

```
main.py (PyInstaller 应用入口)
 │  - 初始化 QApplication
 │  - 创建 MainWindow
 │  - 启动 HTTP 加速服务线程
 │  - app.exec_() 进入 Qt 事件循环
 │
 ├──▶ github_speedup/api/ (API 层)
 │     ├── download_api.py   下载任务创建/取消/删除/持久化
 │     ├── proxy_api.py      代理管理/测速/预检/导入导出
 │     ├── config_api.py     设置读取/保存/重置/记录管理
 │     ├── server_api.py     HTTP 加速服务启停控制
 │     └── logger_api.py     运行时访问日志
 │
 ├──▶ github_speedup/core/ (核心引擎层)
 │     ├── downloader.py     多代理并行分片下载引擎（线程池 20）
 │     ├── proxy_manager.py  代理列表加载/测速/静默管理
 │     ├── settings.py       设置管理
 │     ├── utils.py          共享 Transport/路径/浏览器头
 │     └── logger.py         访问日志写入
 │
 └──▶ github_speedup/gui/ (PySide6 UI 层)
       ├── main_window.py    主窗口（QMainWindow + QStackedWidget）
       ├── download_page.py  下载页（QWidget + QTableWidget）
       ├── proxy_page.py     代理页（QWidget + QTableWidget）
       └── settings_page.py  设置页（QWidget + 表单控件）
```

## 关键设计模式

| 模式 | 实现位置 | 说明 |
|------|---------|------|
| **Worker Pool** | core/downloader.py | queue.Queue + threading.Thread 限并发 |
| **异步任务** | api/download_api.py:create_task | 立即返回 TaskInfo，后台线程下载 |
| **回调** | core/downloader.py:start_background_download | record_success/record_failure/on_progress 回调 |
| **Proxy Rotation** | core/downloader.py | 失败的 part 用不同代理重试 |
| **滑动窗口测速** | core/downloader.py:calc_speed | 最近 10s 速度采样计算 |
