## 关键设计模式

| 模式 | 实现位置 | 说明 |
|------|---------|------|
| **Worker Pool** | main.go:80-200 | 通过 buffered channel + goroutine 实现限并发 |
| **Object Pool** | proxy.go: ProxyPool | 代理对象池，Assign/Release/Fail 管理生命周期 |
| **Decorator** | utils.go: progressReader, trackReader | 包装 io.Reader 增加超时检测和字节跟踪 |
| **Context** | utils.go: context.WithCancel | 超时取消和资源清理 |
| **Strategy** | proxy.go: Fail → requeue at tail | 失败代理轮转策略 |

## 主函数控制流

```
main()
 ├── 1. flag.Parse()          解析命令行参数
 ├── 2. ReadLines(proxyFile)  加载代理列表
 ├── 3. NewProxyPool()        初始化代理池
 ├── 4. GetFileInfo()         获取文件大小
 ├── 5. DivideFileIntoParts() 计算分片
 ├── 6. PrepareOutputPath()   准备输出路径
 ├── 7. SaveContentLength()   保存元数据
 ├── 8. 启动 N 个 Worker      并发下载分片
 │    ├── Assign()            获取代理
 │    ├── DownloadPartialFile() 下载分片
 │    │   ├── HTTP GET (Range)  通过代理请求
 │    │   └── 写入 .N.part      流式写盘
 │    ├── Release() / Fail()   释放/切换代理
 │    └── 循环直到所有分片完成
 ├── 9. ConcatenateFiles()    合并分片
 ├── 10. 验证文件大小
 └── 11. 清理 .info.txt
```
