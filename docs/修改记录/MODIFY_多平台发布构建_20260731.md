# MODIFY 多平台发布构建_20260731

## 修改目标

用户要求为开源仓库生成并发布 8 个平台二进制（Windows x86/x64/arm64、Linux x86/x64/arm64、macOS Intel/ARM），上传到 GitHub Releases。

## 当前代码状态

- 构建方式：PyInstaller + `github-speedup.spec`（此前仅本机 Windows x64 手动构建）。
- `.github/workflows/build.yml` 与 `release.yml` 仍是旧 Go 项目的构建脚本（`go build` + 3 平台），已不适用。
- `.github/release-notes.md` 为版本说明，尚无下载清单。

## 计划修改方案

1. `github-speedup.spec`：增加 `proxies.json` 数据文件；Windows 条件打包 `bin/aria2c.exe`；支持 `TARGET_ARCH` 环境变量（macOS universal2）。
2. `.github/workflows/release.yml`：改为 PyInstaller 矩阵构建，覆盖 5 个 hosted runner（windows-latest、windows-11-arm、ubuntu-latest、ubuntu-24.04-arm、macos-latest），打 tag 自动构建并发布。
3. `.github/workflows/build.yml`：同步为同一矩阵，手动 dispatch 测试用。
4. `.github/release-notes.md`：追加 6 个二进制下载清单与 32 位不可行的说明。

## 可行性结论（关键调研）

- PyInstaller 无法交叉编译，必须每个平台用对应 hosted runner。
- PySide6-Essentials 6.11.1 官方 wheel 仅有：win_amd64、win_arm64、manylinux x86_64、manylinux aarch64、macos universal2。**不存在 win32 / i686 的 32 位 wheel**（Qt6 已停止 32 位支持）。
- 因此 32 位 Windows 与 32 位 Linux 无法构建，其余 6 个目标可行。
- macOS 用 universal2 一次构建，再 `lipo -thin` 拆出 darwin-x86_64 与 darwin-arm64。
