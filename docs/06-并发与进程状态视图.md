## 覆盖范围

## 进程内并发模型

```
┌─────────────────────────────────────────────────────────────────────┐
│                        main goroutine                                 │
│  (解析参数 → 创建资源 → 启动Worker → 等待完成 → 合并文件)              │
└──────────┬──────────────────────────────────┬──────────────────────┘
           │                                  │
           │ 启动                              │ 等待
           ▼                                  ▼
┌──────────────────────┐          ┌─────────────────────────┐
│  Worker Goroutine x N│          │  progressReporter (可选)  │
│  (max 并发数)         │          │  JSON 模式进度上报        │
│                      │          │                          │
│  ┌────────────────┐   │          └─────────────────────────┘
│  │ Worker #1      │   │
│  │ ┌──────────┐   │   │     ┌─────────────────────────┐
│  │ │ Assign() │   │   │     │  timeoutMonitor goroutine │
│  │ │ Range HTTP│   │   │     │  (per worker)            │
│  │ │ .part写盘  │   │   │     │  无数据超时 → cancel ctx  │
│  │ └──────────┘   │   │     └─────────────────────────┘
│  ├────────────────┤   │
│  │ Worker #2     │   │
│  ├────────────────┤   │
│  │ Worker #N     │   │
│  └────────────────┘   │
└──────────────────────┘
```

## 同步机制

```
ProxyPool 线程安全模型：

┌──────────────────────────────────────────────────────────────────┐
│                       ProxyPool                                    │
│                                                                    │
│   ┌──────────────────────────────────────┐                        │
│   │           queue []string              │  ← FIFO 队列           │
│   │           mu    sync.Mutex            │  ← 互斥锁保护          │
│   │           assigned map[string]string  │  ← workerID → proxy   │
│   │           errorCount int              │  ← 全局错误计数        │
│   └──────────────────────────────────────┘                        │
│                                                                    │
│   方法:                                                             │
│   Assign(workerID) → proxyURL     (加锁)                           │
│   Release(workerID)               (加锁 → 放回队首)                │
│   Fail(workerID) → newProxyURL   (加锁 → 放回队尾 → 重新分配)     │
│                                                                    │
│   数据流:                                                           │
│   Worker ──Assign()──▶ ProxyPool ──返回代理──▶ Worker              │
│         ◀──Release()────                                        │
│         ◀──Fail()──────                                        │
└──────────────────────────────────────────────────────────────────┘
```

## 上下文取消链

```
main goroutine (WithCancel)
   │
   ├──▶ Worker #1 (继承 ctx)
   │       │
   │       ├──▶ HTTP Request (WithTimeout)
   │       │       │
   │       │       └──▶ response.Body 读取
   │       │               │
   │       │               ├──▶ 正常读取 → 重置 timer
   │       │               │
   │       │               └──▶ 超时无数据 → cancel → 分片失败
   │       │
   │       └──▶ 完成后 goroutine 退出
   │
   └──▶ 全部 Worker 完成后 cancel()
```

## 关键并发参数

| 参数 | CLI Flag | 默认值 | 说明 |
|------|----------|--------|------|
| 最大并发下载数 | `-max` | 30 | 同时运行的 Worker goroutine 数量 |
| 分片大小 | `-part` | 10 MB | 每个 Worker 下载的字节范围大小 |
| 超时时间 | `-timeout` | 20 秒 | 单次无数据超时阈值 |
| 重试次数 | `-retry` | 2 | 每个代理失败后的重试次数 |
| 代理队列 | 无 | 由 proxies.txt 决定 | 初始代理数量 |
