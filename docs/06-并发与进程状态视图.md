# 视图06-并发与进程状态视图

## 覆盖范围
下载引擎内部的并发模型与状态流转

## 进程内并发模型

```
┌────────────────────────────────────────────────────────────────────┐
│                     main Python 线程 (PySide6)                          │
│  初始化 → GUI 事件循环 → 接收前端调用 → 调度下载                     │
└────────────────────────────────────────────────────────────────────┘
         │
         │ start_download() 触发
         ▼
┌────────────────────────────────────────────────────────────────────┐
│                  后台下载线程 (threading.Thread)                      │
│  _legacy_download：整个下载生命周期                                 │
│   ├── 启动后台探测线程 (获取文件大小)                               │
│   ├── 启动进度 ticker 线程 (0.5s 上报)                              │
│   └── 启动 N 个分片线程 (每片一个)                                  │
└──────────────────┬─────────────────────────────────────────────────┘
                   │
          ┌────────┴────────┐
          │                  │
          ▼                  ▼
┌──────────────────┐  ┌──────────────────────────────┐
│  N 个分片线程     │  │  共享状态 (threading.Lock)     │
│  每片独立下载     │  │  - confirmed_bytes           │
│  ┌────────────┐  │  │  - total_bytes               │
│  │ 切片 #0     │  │  │  - proxy_used 计数           │
│  │ 切片 #1     │  │  │  - speed_history            │
│  │ 切片 #2     │  │  └──────────────────────────────┘
│  │ ...        │  │
│  └────────────┘  │
└──────────────────┘
```

## 分片线程状态机

```
                    ┌──────────┐
                    │  分片就绪  │
                    │  (已分配)  │
                    └────┬─────┘
                         │
                         ▼
                ┌────────────────┐
                │  HTTP GET Range │
                │  (直连镜像代理)  │
                └───────┬────────┘
                        │
               ┌────────┴────────┐
               │                  │
               ▼                  ▼
       ┌──────────────┐  ┌──────────────┐
       │  206 OK       │  │  非 206       │
       │  流式读取 Body │  │  或连接失败    │
       └──────┬───────┘  └──────┬───────┘
              │                  │
              ▼                  ▼
       ┌──────────────┐  ┌──────────────┐
       │  seek(X) 写入 │  │  换下一个代理  │
       │  confirmed += │  │  重试 (循环)  │
       └──────┬───────┘  └──────┬───────┘
              │                 │
              ▼                 ▼
       ┌──────────────┐  ┌──────────────┐
       │  分片完成      │  │  全部代理失败  │
       │  → 结果标记    │  │  → 分片失败   │
       └──────────────┘  └──────────────┘
```

## 取消链

```
PySide6 QApplication 主线程
   │
   └──▶ 后台下载线程
          │
          ├──▶ 分片线程 (定期检查 cancel_evt.is_set())
          │       └──▶ 正在进行的 HTTP 请求被中止
          │
          └──▶ cancel_task(id) 时设置 cancel_evt Event
                   → 所有分片线程检测到取消
                   → HTTP 请求中断
                   → 后台线程退出
```

## 关键并发参数

| 参数 | 默认值 | 位置 | 说明 |
|------|--------|------|------|
| 分片大小 | max(4MB, total/8) | core/downloader.py | 切片大小，上限 8 片 |
| 分片并发 | ≤8 线程 | core/downloader.py | 每片一个线程，直连镜像 |
| 探测超时 | min(timeout,10)s | core/downloader.py | 后台探测文件大小的等待上限 |
| per-proxy 超时 | min(timeout,15)s | core/downloader.py | 每个代理的单请求超时 |
| MaxConcurrent | 20 | core/settings.py | 预留设置项（下载并发） |
| PartSizeBytes | 10 MB | core/settings.py | 预留设置项（分片大小） |
| Timeout | 30 秒 | core/settings.py | HTTP 请求总超时 |
| 代理测试线程数 | 30 | core/proxy_manager.py | 并行测试代理的线程数 |
