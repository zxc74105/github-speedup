## 进程内并发模型

```
┌────────────────────────────────────────────────────────────────────┐
│                     main Python 线程 (PySide6)                          │

└────────────────────────────────────────────────────────────────────┘
         │
         │ CreateTask() 触发
         ▼
┌────────────────────────────────────────────────────────────────────┐
│                  StartBackgroundDownload (Python 线程)                │
│  负责整个下载生命周期                                               │
└──────────────────┬─────────────────────────────────────────────────┘
                   │
         ┌─────────┴──────────┐
         │                    │
         ▼                    ▼
┌──────────────────┐  ┌──────────────────────────────┐
│  20 个 Worker    │  │  Python 任务队列 (Python queue.Queue)     │
│  Python 线程       │  │  承载所有分片 Job              │
│  (for循环+select)  │  │  由主 Python 线程 填充          │
│                  │  │  Worker 从 channel 消费        │
│  ┌────────────┐  │  └──────────────────────────────┘
│  │ Worker #0  │  │
│  │ Worker #1  │  │         ┌──────────────────── ┐

│  │ ...        │  │         │ Worker 完成时写结果   │
│  └────────────┘  │         └─────────────────────┘
└──────────────────┘
```

## Worker 状态机

```
                   ┌──────────┐
                   │  等待 Job  │
                   │  (从channel)│
                   └────┬─────┘
                        │
                        ▼
               ┌────────────────┐
               │  HTTP GET Range │
               │  (使用指定代理)   │
               └───────┬────────┘
                       │
              ┌────────┴────────┐
              │                  │
              ▼                  ▼
      ┌──────────────┐  ┌──────────────┐

      │  流式读取 Body │  │  或连接失败    │
      └──────┬───────┘  └──────┬───────┘
             │                  │
             ▼                  ▼
      ┌──────────────┐  ┌──────────────┐
      │  Body 读完    │  │  加入 failed │
      │  → results   │  │  等待重试     │
      └──────────────┘  └──────┬───────┘
                               │
                               ▼
                        ┌──────────────┐
                        │  重试循环     │
                        │  (用不同代理)  │
                        │  MaxRetry 次  │
                        └──────────────┘
```

## 上下文取消链

```
PySide6 QApplication ctx
   │
   └──▶ StartBackgroundDownload 内部 ctx (WithCancel)
          │
          ├──▶ Worker 1 (检查 ctx.Err())
          │       └──▶ HTTP Request (WithContext)
          │
          ├──▶ Worker 2
          │       └──▶ HTTP Request
          │
          └──▶ CancelDownload(id) 时调用 cancel()
                   → 所有 Worker 收到 ctx 取消
                   → 正在进行的 HTTP 请求立即中断
                   → Python 线程 退出
```

## 关键并发参数

| 参数 | 默认值 | 位置 | 说明 |
|------|--------|------|------|
| MaxConcurrent | 20 | core/downloader.py | 同时运行的 Worker 线程数量 |
| PartSizeBytes | 4 MB | core/downloader.py | 每个分片大小 |
| MaxRetry | 3 | core/downloader.py | 失败分片最大重试次数（换代理） |
| Timeout | 30 秒 | core/downloader.py | HTTP 请求总超时 |
